Problem 1

Bubble Sort with Early Exit

Easy
Bubble sortEarly exitIn place

Given an integer array nums, sort it in place in ascending order using bubble sort.

Your implementation must include the early-exit optimization: track whether any swap happened during a pass. If a full pass makes no swaps, the array is already sorted, so stop immediately.

Examples

Example 1
Input
nums = [5, 2, 4, 1, 3]
Output
nums = [1, 2, 3, 4, 5]
Explanation
After the call the array is sorted in place; the function returns nothing.
Example 2
Input
nums = [1, 2, 3, 4]
Output
nums = [1, 2, 3, 4]
Explanation
Already sorted: the first pass makes no swaps, so the loop exits after one pass. This is the O(n) best case.

Constraints

  • 1 ≤ nums.length ≤ 1000
  • -104 ≤ nums[i] ≤ 104
  • Sort in place, in ascending order. The function returns nothing.
  • Do not use a built-in sort.

Hints

Show hints (open only if you are stuck)
  1. Compare adjacent pairs: for each pass, walk j from 0 to n - 1 - pass and swap nums[j] with nums[j+1] whenever they are out of order.
  2. Reset an swapped flag to false at the start of every pass, set it to true whenever you swap, and stop as soon as a pass finishes with no swaps.
  3. An already-sorted array must take a single pass. If your loop always runs the full n − 1 passes, the early exit is not wired up correctly.

Reference solutionC
// Time: O(n^2) worst, O(n) best (early exit). Space: O(1).
void bubbleSort(int* nums, int numsSize) {
    for (int end = numsSize - 1; end > 0; end--) {
        int swapped = 0;
        // 1. Compare adjacent pairs, bubbling the largest value to the end
        for (int i = 0; i < end; i++) {
            if (nums[i] > nums[i + 1]) {
                int tmp = nums[i];
                nums[i] = nums[i + 1];
                nums[i + 1] = tmp;
                swapped = 1;
            }
        }
        // 2. Early exit: a full pass with no swaps means already sorted
        if (!swapped) {
            break;
        }
    }
}

Problem 2

Insertion Sort: Count the Shifts

Easy
Insertion sortAdaptive sortingCounting

Sort nums in place in ascending order using insertion sort, then return the total number of shifts performed.

A shift is one element moving one position to the right to make room for the key. In the inner loop, each element you pass over and move right counts as one shift. Compare with strict > so that equal elements are never shifted.

The total number of shifts is exactly the number of inversions in the array (the argument is sketched on the notes page).

Examples

Example 1
Input
nums = [5, 2, 4, 1]
Output
return 5 (and nums = [1, 2, 4, 5])
Explanation
Insert 2: 5 shifts once (1). Insert 4: 5 shifts once (2). Insert 1: 5, 4, and 2 each shift once (5 in total).
Example 2
Input
nums = [1, 2, 3]
Output
return 0
Explanation
Already sorted: nothing ever shifts.
Example 3
Input
nums = [2, 2, 2]
Output
return 0
Explanation
Equal keys do not count as out of order, so nothing shifts.

Constraints

  • 1 ≤ nums.length ≤ 1000
  • -104 ≤ nums[i] ≤ 104
  • The shift count fits in a 32-bit integer.
  • Sort in place. Do not use a built-in sort.

Hints

Show hints (open only if you are stuck)
  1. Keep a sorted prefix nums[0..i-1]. For each nums[i], save it as key, shift every larger element one step right, then put key into the hole.
  2. Count one shift per element moved right — that is, inside the inner loop, not once per insertion.

Reference solutionC
// Insertion sort: sorts nums in place and returns the total number of shifts
// (each time an element is moved one position right to make room for the key).
// Time: O(n^2) worst, O(n) best (already sorted). Space: O(1).

int insertionSort(int* nums, int numsSize) {
    int shifts = 0;
    for (int i = 1; i < numsSize; i++) {
        int key = nums[i];
        int j = i - 1;
        // 1. Shift elements greater than the key one position to the right
        while (j >= 0 && nums[j] > key) {
            nums[j + 1] = nums[j];
            shifts++;
            j--;
        }
        // 2. Insert the key into the gap
        nums[j + 1] = key;
    }
    return shifts;
}

Problem 3

Stable Sort by Word Length

Easy–Medium
StabilityInsertion sortMerge sort

Given an array of strings words, return a new array containing the words sorted by length in ascending order.

Words of equal length must keep their original relative order — the sort must be stable. Implement the sorting yourself; built-in sort functions are not allowed.

Insertion sort stays stable if you shift only elements strictly greater than the key; merge sort stays stable if the merge takes from the left half on a tie. Quick sort is not stable, so do not use it here. In C the function sorts the given array of pointers in place; in the other five languages it returns a sorted array.

Examples

Example 1
Input
words = ["pear", "kiwi", "apple", "fig", "banana"]
Output
["fig", "pear", "kiwi", "apple", "banana"]
Explanation
Lengths are 3, 4, 5, 6. “pear” and “kiwi” are both length 4, and “pear” came first, so it stays first.
Example 2
Input
words = ["bb", "aa", "cc"]
Output
["bb", "aa", "cc"]
Explanation
All words have length 2, so a stable sort changes nothing.
Example 3
Input
words = ["ccc", "a", "bb", "ab", "ba"]
Output
["a", "bb", "ab", "ba", "ccc"]
Explanation
“ab” and “ba” are both length 2 and keep their original order.

Constraints

  • 1 ≤ words.length ≤ 1000
  • Each word is 1–100 lowercase English letters.
  • The sort must be stable. Do not use a built-in sort.

Reference solutionC
#include <string.h>

// Sort by length, stably, using insertion sort.
// Time: O(n^2) worst, O(n) best (already ordered by length). Space: O(1).
// NOTE: sorts the array of pointers IN PLACE — the char* entries are
// rearranged; the string contents are never modified.
void sortByLength(char** words, int wordsSize) {
    for (int i = 1; i < wordsSize; i++) {
        char* key = words[i];
        int keyLength = (int)strlen(key);
        int j = i - 1;

        // 1. Shift longer words one slot to the right.
        //    Strict '>' (not >=) keeps equal-length words in original order.
        while (j >= 0 && (int)strlen(words[j]) > keyLength) {
            words[j + 1] = words[j];
            j--;
        }

        // 2. Drop the key into the gap.
        words[j + 1] = key;
    }
}

Problem 4

Count Inversions

Medium
Merge sortCounting64-bit integers

An inversion is a pair of indices (i, j) with i < j and nums[i] > nums[j]. Return the total number of inversions in nums.

A brute-force double loop is O(n2), which is too slow for the largest tests. The expected solution modifies merge sort to count inversions while merging, in O(n log n).

The answer can exceed 231, so use a 64-bit integer type (long long, long, or Python's unbounded int). The function must not destroy the caller's array.

Output
return 6

// Count inversions in O(n log n) by extending merge sort.
// An inversion is a pair (i, j) with i < j and nums[i] > nums[j].
// Time: O(n log n). Space: O(n) for the work copy and the temp array.
// The caller's array is not modified: we copy it before sorting.
// The result type is long long (64-bit) because the answer can exceed 2^31.
#include <stdlib.h>

// Merge the two sorted halves nums[left..mid] and nums[mid+1..right]
// into nums[left..right], and return the inversions between the halves.
static long long mergeAndCount(int* nums, int* temp, int left, int mid, int right) {
    int leftIndex = left;        // next element of the left half
    int rightIndex = mid + 1;    // next element of the right half
    int writeIndex = left;       // next free slot in temp
    long long inversions = 0;

    while (leftIndex <= mid && rightIndex <= right) {
        if (nums[leftIndex] <= nums[rightIndex]) {
            // The left value is not greater, so it forms no inversion.
            temp[writeIndex] = nums[leftIndex];
            writeIndex++;
            leftIndex++;
        } else {
            // nums[rightIndex] is smaller than every remaining left value,
            // and all of them come before it in the original array.
            inversions += (long long)(mid - leftIndex + 1);
            temp[writeIndex] = nums[rightIndex];
            writeIndex++;
            rightIndex++;
        }
    }

    // Copy what is left of one half (the other half is already used up).
    while (leftIndex <= mid) {
        temp[writeIndex] = nums[leftIndex];
        writeIndex++;
        leftIndex++;
    }
    while (rightIndex <= right) {
        temp[writeIndex] = nums[rightIndex];
        writeIndex++;
        rightIndex++;
    }

    // Put the merged run back so nums[left..right] is now sorted.
    for (int index = left; index <= right; index++) {
        nums[index] = temp[index];
    }
    return inversions;
}

// Sort nums[left..right] with merge sort, counting inversions on the way.
static long long mergeSort(int* nums, int* temp, int left, int right) {
    if (left >= right) {
        return 0;  // one element (or none) has no inversions
    }
    int mid = left + (right - left) / 2;
    long long inversions = 0;
    inversions += mergeSort(nums, temp, left, mid);            // 1. sort left half
    inversions += mergeSort(nums, temp, mid + 1, right);       // 2. sort right half
    inversions += mergeAndCount(nums, temp, left, mid, right); // 3. merge and count
    return inversions;
}

long long countInversions(const int* nums, int numsSize) {
    if (numsSize < 2) {
        return 0;
    }

    // Work on a copy so the caller's array is never changed.
    int* work = malloc((size_t)numsSize * sizeof(int));
    int* temp = malloc((size_t)numsSize * sizeof(int));
    if (work == NULL || temp == NULL) {
        free(work);
        free(temp);
        return 0;  // out of memory; cannot happen for n <= 100,000
    }
    for (int i = 0; i < numsSize; i++) {
        work[i] = nums[i];
    }

    long long total = mergeSort(work, temp, 0, numsSize - 1);
    free(work);
    free(temp);
    return total;
}

Problem 5

Quick Sort: Random Pivot, 3-Way Partition

Medium
Quick sortRandomizationDuplicates

Given an integer array nums, return a new array with the same values sorted in ascending order, implemented as quick sort.

Two requirements. First, choose the pivot uniformly at random (pick a random index and move it to the partition position). Second, use a 3-way partition (the Dutch national flag algorithm): after partitioning, all values equal to the pivot are already in their final positions, so you recurse only on the strictly-smaller and strictly-larger regions.

A plain 2-way partition degrades to O(n2) on an array where every value is equal. The 3-way version stays O(n log n) on duplicates. Do not modify the input array.

[1, 2, 3, 4, 5]
Explanation
The input array itself is unchanged.
Example 2

nums = [3, 1, 3, 3, 2, 3]
Output
[1, 2, 3, 3, 3, 3]
Explanation
All four 3s are grouped by the partition and never examined again: that is why duplicates are cheap here.

Problem 6

Kth Largest Element (Quickselect)

Medium+
QuickselectOrder statisticsPartition

Given an integer array nums and an integer k, return the k-th largest element in sorted order — that is, the element at index n - k if the array were sorted ascending. k is 1-based, so k = 1 asks for the maximum.

The expected solution is quickselect: partition like quicksort, but recurse only into the side that contains the target index. Average time O(n), with no need to sort everything.

Sorting the whole array also passes the tests, but it defeats the purpose. Duplicates matter here: [3, 3, 3] with k = 2 must return 3.

Examples

nums = [3, 2, 1, 5, 6, 4], k = 2
Output

Explanation
Sorted: [1, 2, 3, 4, 5, 6]. The second largest is 5.
Example 2
Input

Output

Explanation
Sorted: [1, 2, 2, 3, 3, 4, 5, 5, 6]. Index n - k = 5 holds 4.

  • 1 ≤ k ≤ nums.length ≤ 100,000
  • -104 ≤ nums[i] ≤ 104
  • The array can contain many duplicate values.
  • Do not use a built-in sort. O(n log n) passes, but the point is O(n) on average.

// Returns the pivot's final index: smaller values on the left, larger on the right.
static int partition(int* nums, int left, int right) {

    int offset = rand() % (right - left + 1);
    swapValues(&nums[left + offset], &nums[right]);

    // 2. Move every value smaller than the pivot to the front
    int store = left;
    for (int i = left; i < right; i++) {
        if (nums[i] < pivot) {
            swapValues(&nums[store], &nums[i]);
            store++;
        }

    // 3. Put the pivot between the smaller and larger values
    swapValues(&nums[store], &nums[right]);
    return store;
}

// Swaps two positions in the array, in place.
function swapValues(nums, first, second) {
  const tmp = nums[first];
  nums[first] = nums[second];
  nums[second] = tmp;
}

// Partitions nums[left..right] around a random pivot value.
// Returns the pivot's final index: smaller values left, larger values right.
function partition(nums, left, right) {
  // 1. Pick a random pivot and move it to the right end
  const offset = Math.floor(Math.random() * (right - left + 1));
  swapValues(nums, left + offset, right);
  const pivot = nums[right];

  // 2. Move every value smaller than the pivot to the front
  let store = left;
  for (let i = left; i < right; i++) {
    if (nums[i] < pivot) {
      swapValues(nums, store, i);
      store++;
    }
  }

  // 3. Put the pivot between the smaller and larger values
  swapValues(nums, store, right);
  return store;
}

// Quickselect: returns the value that belongs at targetIndex in sorted order.
function selectValue(nums, left, right, targetIndex) {
  const pivotIndex = partition(nums, left, right);
  if (pivotIndex === targetIndex) {
    return nums[pivotIndex];
  }
  if (pivotIndex < targetIndex) {
    // The target lies to the right: recurse only into that side
    return selectValue(nums, pivotIndex + 1, right, targetIndex);
  }
  // The target lies to the left: recurse only into that side
  return selectValue(nums, left, pivotIndex - 1, targetIndex);
}

function findKthLargest(nums, k) {
  // The kth largest value sits at ascending index nums.length - k.
  const working = nums.slice(); // copy so the caller's array is not modified
  const targetIndex = working.length - k;
  return selectValue(working, 0, working.length - 1, targetIndex);
}
