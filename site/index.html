How our session runs

The session is informal and optional, usually with 5–15 people. Come for all of it or drop in for the part you need.

  1. Concepts first (~20 min). We walk through the four sorts using the notes page: what the algorithm does, when it is fast, and when it degrades.
  2. Practice (~40–50 min). Start with Problem 1 and move at your own speed. Work alone or in pairs; ask questions anytime.
  3. Compare solutions (~10 min). After you have tried a problem, open the reference answer in your language and compare it with your version.
  4. No submission. The exercises are for you, not for a grade. Nothing needs to be uploaded, and no account is required.

What you should already know

These materials assume CS201 (basic Java programming and basic data structures: arrays, linked lists, trees, heaps). In particular you should be comfortable with:

  • arrays and indexing, including swapping two elements;
  • for/while loops and nested loops over a range;
  • comparing numbers and strings, and sorting rules like "ascending order";
  • reading Java-style pseudocode — every algorithm is also given in plain language.

Merge sort (and quick sort) use recursion. If recursion still feels shaky, read the merge sort section of the notes slowly — it is the best place to practice the idea of "solve a smaller piece the same way, then combine".
