How our session runs

Sessions are informal and optional. Bring your questions and work at a pace that helps you understand the material.

  1. Concept review (about 15–20 min). Review the session's key ideas and examples using the notes, with time to clarify unfamiliar concepts.
  2. Practice (30 min). Work on problems independently or in pairs. Choose tasks that match your level; you do not need to finish every problem.
  3. Solution discussion and questions (remaining time). Discuss approaches to selected problems, explain the reasoning, and address questions from your attempts or the lecture.

Recitation exercises are optional, ungraded practice. Nothing needs to be submitted.

What you should already know

These materials build on CS201 (basic programming and data structures: arrays, linked lists, trees, heaps). In particular you should be comfortable with:

  • Java and/or Python as programming languages;
  • arrays and indexing, including swapping two elements;
  • for/while loops and nested loops over a range;
  • comparing values and following basic algorithm steps;
  • understanding the basic concept of time complexity and space complexity;
  • object-oriented programming concepts such as classes, objects, and methods;
  • reading pseudocode and relating it to code in a familiar programming language.

If a prerequisite feels unfamiliar, revisit the relevant notes or ask the TA before beginning the practice problems. Use Recitation 0 to prepare your notebook environment.
